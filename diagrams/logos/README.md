# Icon provenance

These are official website favicons/app icons or icons extracted from installed vendor apps. They are reproduced to identify products in an editorial architecture diagram, without recoloring, and do not imply endorsement. Trademarks remain with their owners. See sources.json for asset origins. Review current vendor brand guidelines before reuse.

The OpenAI installed ChatGPT icon is used as a shared brand identifier with explicit ChatGPT and Codex text labels, rather than claiming a separate Codex product icon. The installed Claude icon identifies Claude Code with an explicit label.

All tools represent the owner’s reported or observed setup, not an end-to-end integration claim. No video production vendor has been selected.
